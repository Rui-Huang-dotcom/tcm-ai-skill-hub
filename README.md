# TCM AI Skill Hub｜中医 AI 学习总入口

> **一次安装，把两个倪海厦、两个 TCM，合成一个更好用的中医 AI 学习入口。**

很多中医 AI Skill 是按作者或单一任务拆开的。最容易让人困惑的是：有两个倪海厦相关项目，也有两个 TCM 相关项目。它们并不冲突，只是资料用途不同；但用户没必要在每次提问前记住该选哪一个。

**TCM AI Skill Hub 的价值，就是把这些同类来源合起来。** 安装一次后，用户直接说“倪海厦”或“TCM”，Hub 会在后台按问题自动调用两套来源中合适的资料；需要同时使用时，会把两边的结论分开标注，而不是混成一个答案。

## 你只需要记住两个总入口

| 你直接说什么 | Hub 自动合并的两套资源 | 你能得到什么 |
|---|---|---|
| **“倪海厦”** | 课程原话、课次、截图与 PDF 证据 + 六经、方证与体系学习 | 既能找“原话在哪”，也能理解“体系怎么讲” |
| **“TCM”** | 教材、方剂、经典出处检索 + 经典系统学习与复盘 | 既能查“依据在哪”，也能安排“接下来怎么学” |

胡希恕、黄元御、吴鞠通、李可等项目也会一并安装。你可以直接点名使用，或让 Hub 帮你做跨学派比较。

## 默认简单模式：直接问，不用选项目

这是大多数人唯一需要的用法。你不必写项目名、内部 ID，也不需要分辨两个倪海厦或两个 TCM。

```text
请用倪海厦的资料解释桂枝汤与麻黄汤的方证差异。
```

Hub 会在“倪海厦课程出处”与“倪海厦体系学习”两套资源中自动找合适的内容；如果答案同时用到两边，会分成“课程出处”和“体系解读”说明。

```text
请用 TCM 帮我安排《伤寒论》三周学习计划。
```

Hub 会把“系统学习规划”和“教材/经典核验”放在同一个学习流程里。你只需要提出问题，不必决定背后该调用哪一个 Skill。

> **简单模式的原则：用户只说任务；Hub 自动合并同类来源。**

## 精确模式：需要时，再限定其中一套

如果你正在做原话核验、课程笔记或严格的资料研究，只要在问题里加一句范围限制即可。仍然不需要记住仓库名。

| 你想要的结果 | 直接这样说 |
|---|---|
| 只找倪海厦课程原话与页码 | `只查倪海厦课程原话、课次、截图或 PDF 页码；不要做体系化解释。` |
| 只按倪海厦体系学习 | `只按倪海厦体系解释，并标注为课程体系观点。` |
| 只查 TCM 教材与经典出处 | `TCM 本次只查教材层和经典原文；请给出出处。` |
| 只做 TCM 系统学习 | `TCM 本次只做《伤寒论》学习计划与复盘训练。` |

> **精确模式的原则：默认合并；你主动限定时，才只调用其中一套。**

## 直接在 Agent 对话框里安装（推荐）

如果你平时使用的是能读取 GitHub、执行安装命令并加载 Skill 的 Agent，直接把下面整段复制到对话框里：

```text
请安装并启用这个项目中的 TCM AI Skill Hub：
https://github.com/Rui-Huang-dotcom/tcm-ai-skill-hub

请按项目 README 安装 Hub 和全部 8 个公开来源项目。安装完成后，告诉我每个来源是否成功，并启用默认简单模式：
- 我说“倪海厦”时，自动合并课程出处检索与体系学习资源；
- 我说“TCM”时，自动合并教材/经典检索与系统学习资源；
- 我明确说“只查课程原话”“只按教材层”等时，进入精确模式，只使用对应来源；
- 不把不同来源的观点混成一个结论；关键结论尽量标出资料来源。
```

安装完成后，你就可以直接开始问：

```text
请用倪海厦解释伤寒论中的桂枝汤与麻黄汤。
```

```text
请用 TCM 解释某条经文，并给我安排下一步学习。
```

## 命令行安装（放在后面，给需要的人）

如果你使用 Claude Code、Cursor、Codex、OpenCode 或 OpenClaw 等本地 Agent，也可以一次执行下面命令：

```bash
npx github:Rui-Huang-dotcom/tcm-ai-skill-hub install-all --agent claude-code --execute
```

把 `claude-code` 换成你的实际 Agent，例如 `cursor`、`codex`、`opencode` 或 `openclaw`。更详细的更新、状态文件和排错说明见 [`docs/INSTALL_ALL.md`](./docs/INSTALL_ALL.md)。

## 回答质量与使用边界

Hub 的回答应先说明资料范围；单一体系的观点单独标注；双来源或跨学派的内容并列呈现，不强行合并；关键结论尽量回到原项目、文件、章节、条文或页码。

本项目仅用于中医学习、资料检索、文献阅读、课程复习与医案研究。它不用于个人诊断、处方、药物剂量判断、自行用药、急症处理或针刺操作。
