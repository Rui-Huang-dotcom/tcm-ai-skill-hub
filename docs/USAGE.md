# 使用指南

本指南说明如何把“中医 AI 学习总 Skill”作为一个统一入口使用。它的关键不是让 AI 一次性“懂所有中医”，而是让学习过程先有资料边界，再有可核验的回答。

## 1. 安装与加载

先下载本仓库。在你的 AI Agent / Skill 平台中，优先加载根目录的 [`SKILL.md`](../SKILL.md)。如果平台支持将 GitHub 项目导入为 Skill，请**同时**按各原作者说明导入你要用的来源项目；总 Skill 只负责选择与约束，并不内置八个项目的资料。

如果平台不支持多 Skill，可以采用简化做法：把 `SKILL.md` 中的“路由流程”“单一体系回答协议”和“跨学派比较协议”作为系统提示词或项目说明；当需要某一来源时，再打开其原始链接阅读 README 或在该平台中单独安装。

| 你的平台能力 | 推荐做法 |
|---|---|
| 可同时加载多个 Skill / 本地文件夹 | 加载总 Skill + 你当前需要的 1–2 个来源项目 |
| 可读取 GitHub 仓库 | 将本仓库作为总说明，再按原作者链接导入来源项目 |
| 只能粘贴文本提示词 | 复制 `SKILL.md` 的路由与回答协议；不要声称已读取未导入的来源 |
| 仅有普通对话框 | 使用下文的提问模板，并将资料范围写在每一次问题开头 |

## 2. 最小可用工作流

每次学习按下面四步即可：

1. **定任务：** 你是查教材、读经典、找课程原话、学某一位医家，还是比较两套体系？
2. **选来源：** 最好只选一套；比较时最多选两到三套，并说明比较目的。
3. **写约束：** 要求回答标明资料范围、文件/章节依据，并区分教材与医家观点。
4. **回原文：** 对重要内容回到原项目、教材或原始文献核验；找不到位置就标“待核”。

## 3. 单一来源提问模板

### 模板 A：查教材或经典

```text
学习任务：我正在复习【课程/书名】中的【概念/条文/方剂】。
资料范围：本次只使用教材层或经典原文层资料，不调用医家观点。
问题：请解释【问题】。
输出要求：
1. 先给出简洁的学习解释；
2. 标明使用的教材章节、条文或文件位置；
3. 找不到依据时请直接说明；
4. 不把内容写成个人诊疗建议。
```

### 模板 B：按某医家体系学习

```text
学习任务：我想研究【医家名称】体系中的【概念/方证/理论问题】。
资料范围：只使用已经加载的【项目名称】资料。
问题：请解释【问题】。
输出要求：
1. 明确标注“【医家名称】体系观点”；
2. 给出可核验的文件、章节、条文或页码依据；
3. 单列与教材通则可能不同或不能直接等同的地方；
4. 最后给我一个文献复盘问题，不要给个人诊疗建议。
```

### 模板 C：查课程原话

```text
学习任务：我需要核对倪海厦课程材料中的一句话或一个说法。
线索：关键词为【关键词】；我记得可能出现在【课次/主题/方剂】附近。
资料范围：只检索已加载的课程出处资料。
输出要求：请返回课程名称、课次、截图或 PDF 位置；无法确认时请标记“待核”，不要用概念性回答替代出处。
```

## 4. 跨学派比较提问模板

比较不是把两套话术混成一个答案。先要求分别陈述，再讨论可比较的范围。

```text
比较任务：请比较【A】与【B】如何讨论【同一个理论问题】。
资料范围：只使用已经加载的【A 项目】与【B 项目】资料。
输出结构：
1. A 的观点与依据；
2. B 的观点与依据；
3. 二者回应的共同学习问题；
4. 主要差异（用表格）；
5. 不应直接合并之处；
6. 两道文献复盘题。
限制：不要把任一方写成唯一标准，不要输出针对现实个体的诊疗、处方或剂量建议。
```

### 一个完整示例

```text
比较任务：请比较胡希恕与黄元御对“理论框架中气机与表里辨证的关系”的解释。
资料范围：只使用已经加载的胡希恕 Skill 与黄元御 Skill。
输出结构：分别说明两家的观点、资料依据、可比较之处、关键差异和不应直接合并之处。
限制：这是课程与文献学习，不要把理论转成对任何人的诊疗建议。
```

## 5. 怎样判断一次回答是否可靠

可以用下面这张表自查：

| 检查项 | 合格信号 | 需要警惕的信号 |
|---|---|---|
| 资料范围 | 明确写出教材、经典或某医家体系 | 说“综合所有资料”，却未说明来源 |
| 来源证据 | 给出文件名、章节、条文、页码或原项目链接 | 只有流畅结论，没有可核验位置 |
| 学派边界 | 清楚标注“某体系观点” | 把一家之言写成中医统一标准 |
| 不确定性 | 找不到时明确说资料不足 | 编造出处、页码或原文 |
| 应用边界 | 停留在学习、文献与复盘 | 直接针对个人给处方、剂量或急症处理方案 |

## 6. 建议的学习记录格式

每次学习后，保留一张简短笔记：

```markdown
- 学习日期：
- 学习任务：
- 资料范围：教材 / 经典 / 某医家体系
- 来源项目与版本：
- 核心概念：
- 可核验位置：
- 与其他体系可能不同之处：
- 我的疑问：
- 下一步要回看的原文：
```

这比积累很多“看起来很专业”的 AI 对话，更容易形成自己的资料链和复盘习惯。

## 7. 常见问题

### Q：我只装总 Skill，不装原项目，可以直接问八位作者的内容吗？

不可以。总 Skill 只提供路由规则与来源目录，不能假装已经拥有或读取各项目资料。它会告诉你应使用哪个原项目，并给出链接与提问规范。

### Q：能不能一次比较所有八个项目？

不建议。比较来源过多会稀释每一套体系的概念边界。先从两套开始，确保每一方都有可核验依据；只有在明确的课程研究任务中，才逐步增加来源。

### Q：能不能把原项目文件都复制到本仓库？

第一版不这样做。是否能复制、改编或再发布取决于各项目的许可证和作者授权。除非逐项核对许可并履行署名、同许可、非商业或其他条件，否则只保留原始链接与独立说明。

### Q：这个 Skill 可以用于患者问题吗？

不可以。本项目仅用于学习、资料检索、文献阅读、课程复习和医案研究；不用于诊断、处方、剂量判断、用药或急症处置。
