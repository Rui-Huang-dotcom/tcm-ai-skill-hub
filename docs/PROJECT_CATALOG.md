# 八个来源项目目录

本目录用于帮助学习者选择资料入口，而非评价项目高低。每一个来源都对应不同的资料范围和学习任务；使用前请先查看原作者 README、项目更新时间和许可证信息。

> 先问“我现在要完成什么学习任务”，再选 Skill；不要只看项目文件多不多、介绍长不长或仓库热度。

| 编号 | 项目 | 最适合的学习任务 | 不应替代的任务 |
|---:|---|---|---|
| 01 | TCM.Skill | 教材、方剂、中药、经典的查阅与知识整理 | 个人诊疗与跨学派定论 |
| 02 | TCM AI Tutor | 连续学习经典、安排复习与医案训练 | 单纯的精确课程原话溯源 |
| 03 | nihaisha-nishi-tcm | 查某一段倪海厦课程原话、截图或 PDF 位置 | 系统性替代课程学习 |
| 04 | 倪海厦 Skill | 梳理倪海厦课程体系中的六经、方证和辨证框架 | 教材标准答案或个人用药判断 |
| 05 | 胡希恕 Skill | 研究六经八纲与方证对应、比较相近方证 | 与其他医家观点混写 |
| 06 | 黄元御 Skill | 理解一气周流、气机升降和相关理论框架 | 以医家语言取代教材通则 |
| 07 | 吴鞠通 Skill | 温病、三焦辨证、卫气营血的课程学习 | 将温病与经方体系强行合并 |
| 08 | 李可 Skill | 有基础后的医案文献复盘与学术研究 | 现实个案处置、剂量或急症决策 |

## 01｜TCM.Skill：查教材与经典

**适合谁：** 刚开始将 AI 用于中医学习，希望查教材概念、方剂、中药或经典出处的学习者。

**用法建议：** 问题里先限定资料层级。例如“本次只使用教材层资料，不调用医家资料和问诊流程。请说明结论对应的教材、章节和文件位置。”如果你的问题来自一本教材，直接给出教材名称和章节，会比笼统提问更容易核验。

**原项目：** [YuanZHAO321/TCM.Skill](https://github.com/YuanZHAO321/TCM.Skill)

## 02｜TCM AI Tutor：系统学习经典

**适合谁：** 不只是想查一个答案，而是希望围绕经典做连续学习、分阶段练习和医案复盘的学习者。

**用法建议：** 先说清楚学习起点、每周可投入时间和目标书目。例如：“我已读完《伤寒论》前 X 部分，请按三周安排设计复盘：每周阅读任务、概念卡片、两道辨析题和一次错题回顾。”完成一个周期后，再让它根据你的回答做学习反馈。

**原项目：** [William84132/tcm-ai-tutor](https://github.com/William84132/tcm-ai-tutor)

## 03｜nihaisha-nishi-tcm：查倪海厦课程原话

**适合谁：** 已经在看相关课程，需要确认“这句话在哪一课”“这个说法是否有课程截图或 PDF 依据”的学习者。

**用法建议：** 把检索目标说具体：关键词、方剂、穴位、课次线索或你记得的句子。优先要求返回课程名称、课次、截图或 PDF 位置；找不到就明确记录“待核”。不要用“记得老师好像说过”代替证据。

**原项目：** [JuneYaooo/nihaisha-nishi-tcm](https://github.com/JuneYaooo/nihaisha-nishi-tcm)

## 04｜倪海厦 Skill：学课程体系与辨证框架

**适合谁：** 已接触相关课程，希望从六经、方证、脉舌等维度梳理课程体系的学习者。

**用法建议：** 明确限定为该体系的学习解读，并要求与院校教材层结论分开陈述。例如：“请按该 Skill 已加载的资料，梳理两个方证的比较框架；单列课程体系观点，不要写成教材统一结论。”

**原项目：** [jangviktor-web/nihaixia](https://github.com/jangviktor-web/nihaixia)

## 05｜胡希恕 Skill：六经八纲与方证比较

**适合谁：** 正在学习《伤寒论》或经方，希望理解六经八纲与方证对应关系，并比较相近方证的学习者。

**用法建议：** 将问题设计成“比较题”，并明确资料范围。例如：“仅按胡希恕体系，比较桂枝汤、麻黄汤、葛根汤的方证要点；将依据、相同点和差异分开写。”学习笔记中应标注“胡希恕体系观点”。

**原项目：** [jangviktor-web/huxishu](https://github.com/jangviktor-web/huxishu)

## 06｜黄元御 Skill：一气周流与气机升降

**适合谁：** 已有基础理论学习，希望研究“一气周流”“土枢四象”及气机升降思路的学习者。

**用法建议：** 先用一个确定的理论概念或原文段落切入，要求先解释术语，再梳理概念之间的关系。初学者应把该体系语言与教材通则分开记录，避免将医家理论直接当作唯一解释。

**原项目：** [jangviktor-web/huangyuanyu](https://github.com/jangviktor-web/huangyuanyu)

## 07｜吴鞠通 Skill：温病与三焦辨证

**适合谁：** 正在学习温病学，希望梳理三焦辨证、卫气营血、病位与治法关系的学习者。

**用法建议：** 从课程中的一个章节或一个明确问题开始，例如“请按吴鞠通温病体系，梳理上、中、下三焦的学习框架；区分病位、证候、相关条文和方剂名称”。不要让 AI 为了“全面”而强行把经方与温病体系融合。

**原项目：** [jangviktor-web/wujutong](https://github.com/jangviktor-web/wujutong)

## 08｜李可 Skill：进阶医案研究

**适合谁：** 已具备一定经典与临床学习基础，准备从公开医案中研究辨证思路、资料出处和学术表达的学习者。

**用法建议：** 只把它当作“医案文本复盘”工具。例如：“请按已加载资料梳理该医案的主诉、证据链、辨证转折和原文位置；不要转化为个人建议、处方或剂量。”遇到真实个案、危急症状或用药问题，应当转向合格专业人员的当面评估。

**原项目：** [jangviktor-web/likeskill](https://github.com/jangviktor-web/likeskill)

## 两个倪海厦相关项目，如何选择

| 你的问题 | 优先项目 | 原因 |
|---|---|---|
| “这句话在哪一课？”“能找到截图或 PDF 位置吗？” | `nihaisha-nishi-tcm` | 重点是课程出处与证据定位 |
| “这一套体系如何理解、比较方证？” | `nihaixia` | 重点是体系化学习与辨证框架 |

二者来自不同作者、解决不同学习任务，并非简单的“新版替代旧版”。

## 使用前的三项检查

1. **查来源。** 先看项目作者、资料范围、更新时间和许可证，避免把不明出处内容当作依据。
2. **查原文。** 重要结论尽量回到教材、条文、课程材料或原项目文件核对；无法定位时就标记为待核。
3. **查边界。** 清楚区分教材结论和医家观点；本目录及全部来源仅作学习与资料研究，不用于个体诊疗。
